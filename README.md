🏛️ Arch-Asset Manager
Sistema de Gerenciamento de Ativos Digitais para Arquitetura
Uma aplicação web ágil desenvolvida para o controle de renders, plantas e metadados técnicos de projetos imobiliários.

📌 Sobre o Projeto
Este sistema foi desenvolvido como projeto prático para a disciplina de Aplicações Rápidas em Python na Estácio Carapicuíba. O foco principal é resolver a desorganização de arquivos digitais em escritórios de arquitetura, permitindo o rastreio rápido do status de cada visualização 3D ou planta baixa.

O projeto utiliza o conceito de RAD (Rapid Application Development), sendo estruturado como uma Single-File Application para demonstrar a eficiência do micro-framework Flask em prototipagem rápida.

🚀 Tecnologias Utilizadas
Python 3.x: Linguagem base.

Flask: Micro-framework para o back-end.

Jinja2: Motor de renderização de templates dinâmicos.

HTML5 & CSS3: Interface limpa e funcional.

⚙️ Funcionalidades
[x] Cadastro de Ativos: Registro de novos projetos com ID, técnica (HDR, V-Ray, etc.) e status.

[x] Dashboard de Listagem: Visualização centralizada dos ativos armazenados.

[x] Relatórios em Tempo Real: Rota dedicada para resumo estatístico do portfólio.

[x] Gerenciamento de Fluxo: Opção de remoção e atualização de status (Aprovado, Em Edição, etc.).

🛠️ Como Executar
Clone o repositório:

Bash
git clone https://github.com/GabrielSouza2006/sistema-gerenciador-para-arquitetura.git
Instale as dependências:

Bash
pip install flask
Execute o servidor:

Bash
python app.py
Acesse: http://localhost:5000
